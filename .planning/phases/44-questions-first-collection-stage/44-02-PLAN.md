  <action>
Create TriageProvider that generates clarifying questions from triage gaps:

1. Class TriageProvider:
   - No LLM dependency (deterministic template questions)
   - generate_triage_question(gap: TriageGap, context: dict) -> QuestionTask

2. Gap-specific question templates (BUTTONS REQUIRED for each):

   UNKNOWN_MODE:
   - question_text: "What would you like me to help with?"
   - options:
     - {label: "Build work items", value: "build", description: "Create epics, stories, or tasks in Jira"}
     - {label: "Architecture review", value: "think", description: "Get analysis and recommendations"}
     - {label: "Record a decision", value: "decide", description: "Capture and track a decision"}
     - {label: "Just chatting", value: "chat", description: "General conversation"}
   - target_field: "triage.mode_hint"

   UNKNOWN_TARGET:
   - question_text: "What is this request about?"
   - options:
     - {label: "Existing ticket", value: "jira_ref", description: "Reference to a Jira issue (paste the key)"}
     - {label: "New idea", value: "new_idea", description: "Something we haven't tracked yet"}
     - {label: "Previous discussion", value: "prior_context", description: "Continuing an earlier thread"}
   - target_field: "triage.target_hint"

   UNKNOWN_SCOPE:
   - question_text: "What type of work item should this be?"
   - options:
     - {label: "Epic", value: "epic", description: "Large initiative with multiple stories", is_recommended: True}
     - {label: "Story", value: "story", description: "User-facing feature"}
     - {label: "Task", value: "task", description: "Technical work item"}
     - {label: "Bug", value: "bug", description: "Something that needs fixing"}
   - target_field: "triage.scope_hint"

   MISSING_TOPIC:
   - question_text: "What topic should I focus on?"
   - question_type: ASK_USER (text input, not buttons)
   - target_field: "triage.topic"

   AMBIGUOUS_INTENT:
   - question_text: "I want to make sure I understand. Can you tell me more about what you need?"
   - question_type: ASK_USER (text input)
   - target_field: "triage.clarification"

3. Priority order for gaps:
   - UNKNOWN_MODE (priority=10) - must know this first
   - UNKNOWN_TARGET (priority=20)
   - UNKNOWN_SCOPE (priority=30)
   - MISSING_TOPIC (priority=40)
   - AMBIGUOUS_INTENT (priority=50)

4. get_next_question(gaps: set[TriageGap], context: dict) -> QuestionTask | None:
   - Sort gaps by priority
   - Return question for highest priority gap
   - Return None if no gaps

Follow QuestionTask schema exactly. Use QuestionType.CONFIRM_SCOPE for button questions, QuestionType.ASK_USER for text input.
