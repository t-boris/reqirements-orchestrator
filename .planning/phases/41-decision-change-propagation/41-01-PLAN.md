# Plan 41-01: DecisionChangeOp Schema + Store

## Objective

Create the DecisionChangeOp entity that tracks decision change operations through their lifecycle: PROPOSED → CONFIRMED → APPLYING → DONE/FAILED/CANCELLED.

## Context

From 41-CONTEXT.md:
- Any decision change must be tracked as an operation
- Operations have impact analysis results attached
- Operations can be confirmed, cancelled, or retried
- Operations follow truth-first ordering: DB → Slack → Jira

### Existing Infrastructure

- `src/db/decision_store.py` - DecisionStore with versioning
- `src/db/decision_link_store.py` - DecisionLinkStore for decision↔Jira mappings
- `src/schemas/decision.py` - Decision, DecisionStatus, DecisionType models

## Tasks

### Task 1: DecisionChangeOp Schema

Create the DecisionChangeOp model with state machine.

**File:** `src/schemas/decision.py`

**Changes:**
1. Add `DecisionChangeOpState` enum:
   ```python
   class DecisionChangeOpState(str, Enum):
       PROPOSED = "proposed"      # Impact analysis in progress
       CONFIRMED = "confirmed"    # User confirmed, ready to apply
       APPLYING = "applying"      # Application in progress
       DONE = "done"              # Successfully applied
       FAILED = "failed"          # Application failed (retryable)
       CANCELLED = "cancelled"    # User cancelled
   ```

2. Add `DecisionChangeOpType` enum:
   ```python
   class DecisionChangeOpType(str, Enum):
       EDIT = "edit"              # Version update (vN → vN+1)
       DEPRECATE = "deprecate"    # Mark as deprecated
       DELETE = "delete"          # Delete (only for unapproved)
   ```

3. Add `ImpactSummary` model:
   ```python
   class ImpactSummary(BaseModel):
       jira_keys: list[str] = []           # Affected Jira tickets
       pinned_artifacts: list[str] = []    # Affected pinned messages
       conflict_count: int = 0             # Tickets with conflicts
       total_affected: int = 0             # Total entities affected
   ```

4. Add `DecisionChangeOp` model:
   ```python
   class DecisionChangeOp(BaseModel):
       id: str                              # UUID
       decision_id: str                     # Target decision
       operation: DecisionChangeOpType
       from_version: int
       to_version: Optional[int] = None    # None for deprecate/delete
       actor: str                          # User who initiated
       state: DecisionChangeOpState = DecisionChangeOpState.PROPOSED
       impact_summary: Optional[ImpactSummary] = None
       created_at: datetime
       confirmed_at: Optional[datetime] = None
       completed_at: Optional[datetime] = None
       error_details: Optional[str] = None
   ```

### Task 2: DecisionChangeOpStore

Create the store with CRUD operations.

**File:** `src/db/decision_change_op_store.py` (NEW)

**Operations:**
1. `create_tables()` - Create decision_change_ops table
2. `create(decision_id, operation, from_version, to_version, actor)` - Create new op
3. `get(op_id)` - Get by ID
4. `get_for_decision(decision_id, state=None)` - Get ops for a decision
5. `update_state(op_id, state, error_details=None)` - Transition state
6. `set_impact(op_id, impact_summary)` - Set impact analysis result
7. `confirm(op_id)` - Transition to CONFIRMED
8. `cancel(op_id)` - Transition to CANCELLED
9. `complete(op_id)` - Transition to DONE
10. `fail(op_id, error_details)` - Transition to FAILED

**Table Schema:**
```sql
CREATE TABLE decision_change_ops (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    decision_id UUID NOT NULL,
    operation TEXT NOT NULL,
    from_version INTEGER NOT NULL,
    to_version INTEGER,
    actor TEXT NOT NULL,
    state TEXT NOT NULL DEFAULT 'proposed',
    impact_summary JSONB,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    confirmed_at TIMESTAMPTZ,
    completed_at TIMESTAMPTZ,
    error_details TEXT
);

CREATE INDEX idx_decision_change_ops_decision ON decision_change_ops(decision_id);
CREATE INDEX idx_decision_change_ops_state ON decision_change_ops(state);
```

### Task 3: State Machine Validation

Add state transition validation to prevent invalid state changes.

**File:** `src/db/decision_change_op_store.py`

**Valid Transitions:**
- PROPOSED → CONFIRMED, CANCELLED
- CONFIRMED → APPLYING, CANCELLED
- APPLYING → DONE, FAILED
- FAILED → APPLYING (retry), CANCELLED
- DONE → (terminal)
- CANCELLED → (terminal)

**Implementation:**
```python
VALID_TRANSITIONS = {
    DecisionChangeOpState.PROPOSED: {DecisionChangeOpState.CONFIRMED, DecisionChangeOpState.CANCELLED},
    DecisionChangeOpState.CONFIRMED: {DecisionChangeOpState.APPLYING, DecisionChangeOpState.CANCELLED},
    DecisionChangeOpState.APPLYING: {DecisionChangeOpState.DONE, DecisionChangeOpState.FAILED},
    DecisionChangeOpState.FAILED: {DecisionChangeOpState.APPLYING, DecisionChangeOpState.CANCELLED},
    DecisionChangeOpState.DONE: set(),
    DecisionChangeOpState.CANCELLED: set(),
}

def _validate_transition(self, current: DecisionChangeOpState, target: DecisionChangeOpState) -> None:
    if target not in VALID_TRANSITIONS[current]:
        raise ValueError(f"Invalid state transition: {current} → {target}")
```
