# Plan 41-02: Impact Analysis Service

## Objective

Create the ImpactAnalysisService that computes which entities are affected when a decision changes. This analysis runs automatically when a change operation is created.

## Context

From 41-CONTEXT.md:
- Impact analysis must show:
  - Which Jira issues reference this decision
  - Which pinned messages/indexes depend on it
  - Preflight conflicts (Jira updated externally?)
  - Risk level: how many objects, which fields

### Existing Infrastructure

- `src/db/decision_link_store.py` - `get_links_for_decision()`, `get_pending_syncs()`
- `src/sync/decision_preflight.py` - `DecisionPreflightService.check_batch_sync()`
- `src/sync/preflight.py` - `ConflictType` enum (IDEMPOTENT, SAFE_DRIFT, REAL_CONFLICT, STRUCTURAL)

### Task 2: ImpactAnalysisService

Create the service that computes impact.

**File:** `src/sync/impact_analysis.py` (NEW)

**Class:** `ImpactAnalysisService`

**Dependencies:**
- `DecisionLinkStore`
- `DecisionPreflightService`
- `JiraService` (for preflight)

**Methods:**
1. `analyze(decision: Decision, operation: DecisionChangeOpType) -> ImpactSummary`
   - Get all links for decision
   - Run preflight on each linked ticket
   - Classify results (synced/pending/conflict/structural)
   - Compute risk level
   - Return ImpactSummary

2. `_compute_risk_level(impact: ImpactSummary) -> str`
   - none: no affected entities
   - low: 1-3 synced tickets, no conflicts
   - medium: 4-10 tickets OR any pending syncs
   - high: 10+ tickets OR any conflicts OR structural issues

**Implementation:**
```python
class ImpactAnalysisService:
    def __init__(
        self,
        jira_service: JiraService,
        link_store: DecisionLinkStore,
        decision_store: DecisionStore,
    ):
        self._jira = jira_service
        self._links = link_store
        self._decisions = decision_store
        self._preflight = DecisionPreflightService(
            jira_service=jira_service,
            decision_store=decision_store,
            link_store=link_store,
        )

    async def analyze(
        self,
        decision: Decision,
        operation: DecisionChangeOpType,
    ) -> ImpactSummary:
        # Get all links
        links = await self._links.get_links_for_decision(decision.id)

        if not links:
            return ImpactSummary(
                total_affected=0,
                has_jira_writes=False,
                risk_level="none",
            )

        # Run preflight
        preflight_results = await self._preflight.check_batch_sync(decision)

        # Build impact tickets
        tickets = []
        conflict_count = 0
        pending_count = 0
        safe_count = 0

        for pr in preflight_results:
            if pr.conflict_type == ConflictType.STRUCTURAL:
                tickets.append(ImpactTicket(
                    jira_key=pr.jira_key,
                    sync_status="structural",
                    conflict_type=pr.conflict_type.value,
                    message=pr.message,
                ))
                conflict_count += 1
            elif pr.conflict_type == ConflictType.REAL_CONFLICT:
                tickets.append(ImpactTicket(
                    jira_key=pr.jira_key,
                    sync_status="conflict",
                    conflict_type=pr.conflict_type.value,
                    message=pr.message,
                ))
                conflict_count += 1
            elif pr.conflict_type == ConflictType.IDEMPOTENT:
                tickets.append(ImpactTicket(
                    jira_key=pr.jira_key,
                    sync_status="synced",
                ))
                safe_count += 1
            else:  # SAFE_DRIFT or needs sync
                link = next((l for l in links if l.jira_key == pr.jira_key), None)
                tickets.append(ImpactTicket(
                    jira_key=pr.jira_key,
                    sync_status="pending",
                    last_synced_version=link.synced_version if link else None,
                ))
                pending_count += 1

        impact = ImpactSummary(
            jira_keys=[t.jira_key for t in tickets],
            tickets=tickets,
            conflict_count=conflict_count,
            pending_count=pending_count,
            safe_count=safe_count,
            total_affected=len(tickets),
            has_jira_writes=pending_count > 0 or operation == DecisionChangeOpType.DEPRECATE,
        )
        impact.risk_level = self._compute_risk_level(impact)

        return impact
```

### Task 3: Integration with DecisionChangeOpStore

Auto-run impact analysis when change op is created.

**File:** `src/db/decision_change_op_store.py`

**Changes:**
1. Add `set_impact_from_analysis()` method that takes ImpactAnalysisService result
2. Update impact_summary JSON serialization

**File:** `src/sync/impact_analysis.py`

**Add convenience function:**
```python
async def analyze_and_update_op(
    op: DecisionChangeOp,
    decision: Decision,
    op_store: DecisionChangeOpStore,
    jira_service: JiraService,
    link_store: DecisionLinkStore,
    decision_store: DecisionStore,
) -> ImpactSummary:
    """Analyze impact and update the change op with results."""
    service = ImpactAnalysisService(jira_service, link_store, decision_store)
    impact = await service.analyze(decision, op.operation)
    await op_store.set_impact(op.id, impact)
    return impact
```
