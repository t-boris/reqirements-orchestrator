  <action>
Create new schema file with:

1. **TaskStatus enum:**
   - PENDING: Not yet started
   - RUNNING: Currently executing
   - BLOCKED: Waiting for user input or dependency
   - DONE: Completed successfully
   - CANCELED: Stopped by user or system

2. **SafetyLevel enum:**
   - AUTO_EXECUTE: Safe to run without confirmation (THINK, CHAT tasks)
   - REQUIRES_CONFIRMATION: Needs user approval (BUILD, OPERATE, DECIDE tasks)

3. **SideEffect enum:**
   - NONE: Pure read/analysis
   - SLACK: Posts messages
   - JIRA: Creates/updates Jira
   - REGISTRY: Modifies local registry

4. **Task model (Pydantic):**
   ```python
   class Task(BaseModel):
       task_id: str  # UUID
       mode: SuperMode  # User-facing mode
       intent: Intent  # Internal routing intent
       title: str  # Human-readable title
       status: TaskStatus = TaskStatus.PENDING
       safety_level: SafetyLevel
       side_effects: list[SideEffect] = []
       depends_on: list[str] = []  # task_ids
       target: Optional[str] = None  # anchor: channel|thread|decision_id|jira_key
       params: dict[str, Any] = {}  # Intent-specific params
       progress: Optional[dict] = None  # {current, total} for batch ops
       requires_user_input: bool = False
       last_error: Optional[str] = None
       started_at: Optional[datetime] = None
       completed_at: Optional[datetime] = None
   ```

5. **TaskPlanStatus enum:**
   - PENDING: Plan created, not started
   - RUNNING: At least one task running
   - BLOCKED: All tasks blocked or waiting
   - DONE: All tasks complete
   - CANCELED: Plan canceled by user

6. **TaskPlan model:**
   ```python
   class TaskPlan(BaseModel):
       plan_id: str  # UUID
       channel_id: str
       thread_ts: Optional[str]
       anchor: Optional[str]  # Primary object this plan operates on
       tasks: list[Task]
       status: TaskPlanStatus = TaskPlanStatus.PENDING
       created_by: str  # user_id
       ui_message_ts: Optional[str]  # Status card message
       version: int = 1  # For button idempotency
       created_at: datetime
       updated_at: datetime
   ```

Add helper methods:
- `get_next_pending_task()` → finds first PENDING task with all deps DONE
- `get_blocked_tasks()` → tasks waiting for user input
- `all_done()` → True if all tasks DONE
- `has_running()` → True if any task RUNNING
- `increment_version()` → bumps version, sets updated_at

```python
        """Cancel entire plan (all non-DONE tasks → CANCELED)."""
```

```sql
-- Phase 35: Multi-Intent Task Orchestration
-- TaskPlan storage for multi-intent execution

CREATE TABLE IF NOT EXISTS task_plans (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    plan_id TEXT UNIQUE NOT NULL,
    channel_id TEXT NOT NULL,
    thread_ts TEXT,
    anchor TEXT,
    tasks JSONB NOT NULL DEFAULT '[]',
    status TEXT NOT NULL DEFAULT 'pending',
    created_by TEXT NOT NULL,
    ui_message_ts TEXT,
    version INTEGER NOT NULL DEFAULT 1,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

-- Index for thread lookup (find active plan for thread)
CREATE INDEX IF NOT EXISTS idx_task_plans_thread
ON task_plans(channel_id, thread_ts)
WHERE status NOT IN ('done', 'canceled');

-- Index for channel lookup (all plans in channel)
CREATE INDEX IF NOT EXISTS idx_task_plans_channel
ON task_plans(channel_id);

-- Add cleanup for old completed plans (optional, after 7 days)
-- This can be done via cron job, not automatic
```
