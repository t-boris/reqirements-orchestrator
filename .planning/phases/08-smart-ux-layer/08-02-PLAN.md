```sql
-- Intent audit log for debugging "why did the bot do that?"
-- Append-only, monthly partitions, 90-day retention

CREATE TABLE IF NOT EXISTS intent_audit_log (
    id              BIGSERIAL,
    created_at      TIMESTAMPTZ NOT NULL DEFAULT now(),

    -- Message context
    channel_id      TEXT NOT NULL,
    thread_ts       TEXT,
    message_ts      TEXT NOT NULL,
    user_id         TEXT NOT NULL,
    message_text    TEXT NOT NULL,

    -- PreGate stage
    pregate_result  TEXT,
    pregate_data    JSONB,

    -- LLM classification stage
    raw_mode        TEXT,
    raw_confidence  FLOAT,
    classified_mode TEXT NOT NULL,
    classified_confidence FLOAT NOT NULL,
    entity_type     TEXT,
    target_entity_id TEXT,
    entities_mentioned JSONB,
    reasoning       TEXT,

    -- Performance
    classification_ms INTEGER,

    PRIMARY KEY (id, created_at)
) PARTITION BY RANGE (created_at);

-- Create partitions for current and next 2 months
-- (In production, a cron job would create future partitions)
CREATE TABLE IF NOT EXISTS intent_audit_log_default PARTITION OF intent_audit_log DEFAULT;
```

3. Create `src/infrastructure/audit_log.py`:
- `IntentAuditEntry` Pydantic model with all fields matching the table
- `log_intent_audit(entry: IntentAuditEntry)` — fire-and-forget async function:
  - Creates `asyncio.Task` to write the entry
  - Uses `_background_tasks: set[asyncio.Task]` strong reference set to prevent GC
  - `task.add_done_callback(_background_tasks.discard)` for auto-cleanup
- `_write_audit_entry(entry)` — actual DB write:
  - Gets pool from `get_pool()`
  - Uses `conn.execute(INSERT_SQL, ...)` with parameterized query
  - Catches and logs exceptions (never raises — fire-and-forget)
- `ensure_audit_table()` — runs the migration SQL on startup:
  - Reads the SQL file and executes it
  - Called from app startup (idempotent with IF NOT EXISTS)
- `query_audit_log(channel_id, thread_ts=None, message_ts=None, limit=50)` — query function for /maro inspect:
  - Returns list of IntentAuditEntry
  - Filters by channel_id, optional thread_ts and message_ts
  - ORDER BY created_at DESC, LIMIT

CRITICAL: All DB writes are fire-and-forget. Audit logging must NEVER slow down message processing or cause errors to propagate to the user.

```python
import time

async def classify_intent(...) -> IntentClassification:
    start_ms = int(time.time() * 1000)

    # Stage 1: PreGates (existing code)
    pregate_result = check_pregates(...)

    pregate_result_str = pregate_result.result.value if pregate_result.result != PreGateResult.PASS_THROUGH else None
    pregate_data = pregate_result.data

    if pregate_result.result != PreGateResult.PASS_THROUGH:
        result = _pregate_to_classification(pregate_result)
        elapsed_ms = int(time.time() * 1000) - start_ms

        # Log audit entry (fire-and-forget)
        log_intent_audit(IntentAuditEntry(
            channel_id=context.channel_id,
            thread_ts=context.thread_ts,
            message_ts="",  # Not available here
            user_id="",     # Not available here
            message_text=message[:500],
            pregate_result=pregate_result_str,
            pregate_data=pregate_data,
            raw_mode=result.mode.value,
            raw_confidence=result.confidence,
            classified_mode=result.mode.value,
            classified_confidence=result.confidence,
            entity_type=result.entity_type.value if result.entity_type else None,
            target_entity_id=result.target_entity_id,
            entities_mentioned=result.entities_mentioned,
            reasoning=result.reasoning,
            classification_ms=elapsed_ms,
        ))
        return result

    # Stage 2: LLM Router (existing code)
    result = await _llm_classify(message, context)
    elapsed_ms = int(time.time() * 1000) - start_ms

    # Log with both raw and final classification
    log_intent_audit(IntentAuditEntry(
        channel_id=context.channel_id,
        thread_ts=context.thread_ts,
        message_ts="",
        user_id="",
        message_text=message[:500],
        pregate_result=pregate_result_str,
        pregate_data=pregate_data,
        raw_mode=result.mode.value,  # Before threshold adjustment
        raw_confidence=result.confidence,
        classified_mode=result.mode.value,  # After threshold
        classified_confidence=result.confidence,
        entity_type=result.entity_type.value if result.entity_type else None,
        target_entity_id=result.target_entity_id,
        entities_mentioned=result.entities_mentioned,
        reasoning=result.reasoning,
        classification_ms=elapsed_ms,
    ))
    return result
```

NOTE: To capture raw vs classified mode, refactor _llm_classify to return the raw result, then apply thresholds separately. Store raw_mode/raw_confidence BEFORE threshold adjustment, classified_mode/classified_confidence AFTER.
