1. In `src/slack/handlers/actions.py`, add a handler for question answer buttons:
- Register a regex pattern `re.compile(r"^answer_q_.+$")` for question answer clicks
- On click: extract answer from action value JSON
- Call `client.chat_update()` on the original message to replace buttons with the selected answer (showing "Q: ... A: ..." format)
- Post the answer as a new thread message so the conversation flow continues naturally
- The answer message will be picked up by the normal message handler and processed through intent classification

Pattern for the handler:
```python
@app.action(re.compile(r"^answer_q_.+$"))
async def handle_question_answer(ack, body, action, client, say):
    await ack()

    value = json.loads(action.get("value", "{}"))
    answer = value.get("answer", "")
    question = value.get("question_text", "")
    thread_ts = value.get("thread_ts")

    channel_id = body.get("channel", {}).get("id")
    message_ts = body.get("message", {}).get("ts")
    user_id = body.get("user", {}).get("id")

    # Update original message to show selection (disable buttons)
    if message_ts and channel_id:
        await client.chat_update(
            channel=channel_id,
            ts=message_ts,
            blocks=[{
                "type": "section",
                "text": {"type": "mrkdwn", "text": f"*Q:* {question}\n*A:* {answer}"},
            }],
            text=f"Q: {question} A: {answer}",
        )

    # If "Something else" was clicked, prompt for free-form input
    if answer == "__freeform__":
        await say(
            text=f"<@{user_id}> Go ahead, type your answer:",
            thread_ts=thread_ts,
        )
        return

    # Post the answer as a thread message so intent classification picks it up
    await say(
        text=answer,
        thread_ts=thread_ts,
    )
```

2. IMPORTANT: This new handler MUST be registered BEFORE the catch-all `re.compile(".*")` handler in actions.py. Move the catch-all to the end of `register_action_handlers()`.

3. Register the new handler in `register_action_handlers()` function — it already exists in actions.py, just add the new `@app.action` inside that function.
