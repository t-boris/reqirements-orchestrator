## Decisions Made

1. **LLM semantic conflict detection** - Use LLM to check if values semantically contradict, not just string comparison. This prevents false positives when one value refines another.

2. **Block updates on conflict** - When conflict detected, don't update the field. Store conflict and return action=conflict for UI display. Field stays unchanged until user resolves.

3. **Same-user updates allowed** - No conflict check if same user is updating. Conflicts only matter when different users provide contradicting information.

4. **Preserve full attribution** - Each ConflictSide stores both content and MessageAttribution. Resolution applies the chosen attribution.
