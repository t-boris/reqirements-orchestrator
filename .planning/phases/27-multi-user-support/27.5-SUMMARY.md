## Decisions Made

1. **Creator as first owner:** When a WorkItem is created, the creator is automatically added to the owners array. This ensures every WorkItem has at least one responsible party.

2. **Non-blocking audit logging:** Audit log failures are caught and logged as warnings but don't fail the main operation. This ensures audit infrastructure issues don't impact user experience.

3. **Skill-layer audit logging:** Audit logging was added at the skill layer (jira_create.py, draft.py) rather than the low-level Jira client because the skill layer has full context (channel_id, thread_ts, user_id) needed for meaningful audit entries.

4. **Structured explain output:** The build_explain_output() function returns a structured response showing intent, state, flow reasoning, next steps, and recent audit trail. This replaces LLM-generated explanations for `/maro explain` requests.
