     Currently decision items render as:
     ```

     ```

     Change to include status indicators:
     - Draft/Proposed: `📝 Title` (or just title — these are in-progress)
     - Committed: `✅ Title` (active, projected to Jira)
     - Deprecated: `~~Title~~ (superseded)` with strikethrough

     ```python
     for item in decision_items[:5]:
         title = item.get("title", "Untitled")
         link = item.get("link")

         elif status == "committed":
             display = f":white_check_mark: {title}"
         else:
             display = title

         text = f"* <{link}|{display}>" if link else f"* {display}"
     ```
