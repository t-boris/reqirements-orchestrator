     ```python
     class DecisionAmended(DomainEvent):
         """Decision content updated after recording.

         Emitted when a decision's content is modified (e.g., team changed their mind
         in a thread discussion). Preserves the full previous content for audit trail.
         """
         entity_id: EntityId
         previous_content: DecisionContent  # Snapshot for audit
         new_content: DecisionContent
         reason: str
         new_adr_message_ts: str | None = None  # If ADR message was re-posted
     ```

  Add `DecisionAmended` to `_CORE_EVENT_TYPES` list in the Decision Events section.

  2. In channel.py, add an `amend_decision` method to `ChannelAggregate` (after `record_decision`):

     ```python
     def amend_decision(
         self,
         entity_id: EntityId,
         actor_id: UserId,
         new_content: DecisionContent,
         reason: str,
         new_adr_message_ts: str | None = None,
     ) -> DraftEntity:
     ```

     This method must:
     - Look up entity by entity_id, raise EntityNotFoundError if missing
     - Accept DraftEntity or ProposedEntity (use `can_modify()` from transitions — if entity is not Draft/Proposed, raise InvalidStateError)
     - Create a NEW entity of the SAME type with updated content and incremented version
     - For DraftEntity: create new DraftEntity with new_content, same id/channel/thread/attribution, version+1, new_adr_message_ts (or keep old)
     - For ProposedEntity: create new ProposedEntity with new_content, same id/channel/thread/attribution/canonical_message_ts/approvals/objections, version+1, new_adr_message_ts (or keep old)
     - Emit DecisionAmended event with previous_content snapshot
     - Update self.entities[entity_id]
     - Return the updated entity

  3. In channel.py `_apply_event`, add a case for `DecisionAmended`:
     - Look up existing entity
     - If DraftEntity: reconstruct with new content, version+1, new_adr_message_ts
     - If ProposedEntity: reconstruct with new content, version+1, new_adr_message_ts, preserve approvals/objections

  4. Add `DecisionAmended` to the imports in channel.py.

  IMPORTANT: Entities are frozen Pydantic models — you cannot mutate them. Always create a new instance with updated fields. Use the same pattern as `add_approval()` in transitions.py.

  IMPORTANT: Do NOT clear approvals/objections on amendment. The team may have already approved — amendments to rationale/alternatives shouldn't reset votes. If the decision text itself changes substantially, that's a social contract, not a technical one.
