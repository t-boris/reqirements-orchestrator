If not, store in the content JSONB blob (as `content['adr_message_ts']`).

Update the SQL in `_amend_decision_content`:
```python
async def _amend_decision_content(self, event: DecisionAmended) -> None:
    async with self.pool.acquire() as conn:
        content = self._serialize_content(event.new_content)
        # Store adr_message_ts if available
        adr_ts = getattr(event, 'new_adr_message_ts', None)
        await conn.execute(
            """
            UPDATE entities_view
            SET content = $1, version = $2, adr_message_ts = $3, updated_at = NOW()
            WHERE id = $4
            """,
            content,
            event.version,
            adr_ts,
            str(event.entity_id),
        )
```

If the column doesn't exist, add it to the schema or use a different storage approach (adapt based on discovery in Task 1).
