<objective>
Add lifecycle UI to pinned ADR messages (ISS-001) — the most impactful UX gap.

Purpose: Pinned ADR messages are plain formatted text with no interactive elements. Users cannot tell whether a decision is Draft, Proposed, Approved, or Committed from the pinned message. The only way to advance the lifecycle is through the original thread — which is easy to lose.

Output:
- Pinned ADR messages include status badge (Draft / Proposed / Approved / Committed / Deprecated)
- Pinned ADR messages include lifecycle action buttons appropriate to current state
- Pinned messages update automatically when lifecycle transitions happen via `chat_update`
</objective>
