- Implemented sync_to_jira() for pushing WorkItem changes to Jira

  - Uses section-level fingerprinting for description conflict detection
  - Returns SyncResult with fields_updated, conflicts, and error info
- Implemented sync_from_jira() for pulling Jira changes to WorkItem

- Implemented _check_jira_description_changes() for hotfix detection
- Implemented _rebuild_description() for merging sections back into structured description
- Implemented create_in_jira() for explicit Jira creation
  - Maps WorkItemType to JiraIssueType
  - Updates WorkItem with jira_key and fingerprint
  - Creates commit log entry for audit trail
- Implemented SyncConflict class for UI presentation
- Exported JiraSyncService from jira package __init__.py
