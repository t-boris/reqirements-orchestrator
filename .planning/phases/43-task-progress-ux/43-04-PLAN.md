# 43-04: Visual State Transition Feedback

## Objective
Improve visual feedback when tasks change state (pending → running → done).

## Current State
- Status emoji changes: ⏳→🔄→✅
- No animation or emphasis on state change
- Users must re-read the list to notice changes

## Problem
When a task completes and another starts, the visual change is subtle. Users may miss that progress is happening.

## Solution
Enhance state transitions with visual emphasis and brief highlighting.

## Tasks

### 1. Add state change indicator to status card
**File:** `src/slack/blocks/task_plan.py`

When a task just changed state (within last 3 seconds):
- Add emphasis marker: `2) :arrows_counterclockwise: *BUILD*: Generate stories :new:`
- Use `:new:` emoji for recently started tasks
- Use `:sparkles:` for recently completed tasks

### 2. Track last state change timestamp
**File:** `src/schemas/task_plan.py`

Add field to Task:
```python
state_changed_at: Optional[datetime] = None  # When status last changed
```

Update this whenever status changes.

### 3. Update status change logic
**File:** `src/db/task_plan_store.py` or task executor

When updating task status:
- Set `state_changed_at = now()`
- Ensure timestamp propagates to status card

### 4. Add "just completed" summary to card footer
**File:** `src/slack/blocks/task_plan.py`

In footer context, show recently completed tasks:
```
Just completed: Check duplicates (2s ago)
```

This gives immediate feedback without requiring users to scan the list.

### 5. Enhance SIGNIFICANT_EVENTS for state changes
**File:** `src/slack/task_status_updater.py`

Ensure state transitions bypass throttle:
- Add "task_state_changed" to SIGNIFICANT_EVENTS
- Ensure transitions trigger immediate update

## Acceptance Criteria
- [ ] State changes trigger immediate card update
- [ ] Recently changed tasks have visual indicator
- [ ] Footer shows just-completed task name
- [ ] Visual indicators fade after ~5 seconds
- [ ] No visual clutter for fast consecutive changes
