# 43-03: Elapsed Time Indicator

## Objective
Show how long operations have been running so users know the bot isn't stuck.

## Current State
- `Task.started_at` and `Task.completed_at` timestamps exist
- No elapsed time displayed in status card
- Long operations leave users wondering if MARO is stuck

## Problem
When operations take 10+ seconds, users have no feedback about progress. They may think the bot is frozen or unresponsive.

## Solution
Add elapsed time display for running tasks, updating periodically.

## Tasks

### 1. Add elapsed time formatter utility
**File:** `src/slack/blocks/task_plan.py`

Add helper function:
```python
def format_elapsed_time(started_at: datetime) -> str:
    """Format elapsed time as human-readable string.

    Returns:
        "<5s" for very short
        "15s" for seconds
        "1m 30s" for longer
    """
```

### 2. Display elapsed time in status card
**File:** `src/slack/blocks/task_plan.py`

In `build_task_plan_blocks()`, for RUNNING tasks with `started_at`:
- Show elapsed time after status: `2) :arrows_counterclockwise: *BUILD*: Generate stories (45s)`
- Only show if >5 seconds elapsed (don't clutter fast ops)

### 3. Add periodic refresh for long-running tasks
**File:** `src/slack/task_status_updater.py`

Add method to trigger periodic updates:
```python
async def start_elapsed_timer(self, task_plan: TaskPlan, channel_id: str) -> None:
    """Start a background task that updates elapsed time every 5s."""

async def stop_elapsed_timer(self, plan_id: str) -> None:
    """Stop the elapsed timer for a plan."""
```

Timer should:
- Update every 5 seconds while task is RUNNING
- Respect throttling (combine with other updates)
- Auto-stop when task completes
- Not block main execution

### 4. Integrate timer with task lifecycle
**File:** `src/slack/handlers/dispatch/task_plan.py`

- Start timer when task starts running
- Stop timer when task completes/fails/blocks
- Handle cleanup on plan completion

## Acceptance Criteria
- [ ] Running tasks show elapsed time after 5s
- [ ] Time updates every ~5 seconds
- [ ] Timer stops immediately when task completes
- [ ] No resource leaks from orphaned timers
- [ ] Elapsed time format is readable (1m 30s, not 90s)
