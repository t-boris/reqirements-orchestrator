# 43-01: Single-Task Status Card Display

## Objective
Ensure status cards are displayed even when there's only one task, so users always see what MARO is working on.

## Current State
- `build_task_plan_blocks()` in `src/slack/blocks/task_plan.py` renders TaskPlan with any number of tasks
- `TaskStatusUpdater.post_initial_card()` posts the card when a TaskPlan is created
- Single-intent requests don't create a TaskPlan, so no status card is shown

## Problem
When a user sends a single-intent message, MARO processes it without any visual feedback. The user sees nothing until the final response.

## Solution
Create a minimal status card for single-task operations that shows the action in progress.

## Tasks

### 1. Create single-task status builder
**File:** `src/slack/blocks/task_plan.py`

Add function `build_single_task_blocks(action_text: str, status: str = "running") -> list[dict]`:
- Returns minimal Slack blocks for single action display
- Shows emoji based on status (running spinner, done checkmark)
- Format: `:arrows_counterclockwise: Working on: {action_text}`

### 2. Add single-task status posting to dispatch
**File:** `src/slack/handlers/dispatch/__init__.py` or appropriate handler

When processing a single-intent request (not TaskPlan):
- Post a single-task status card at start
- Update to "done" when complete
- Delete the card if the response is short/immediate

### 3. Create SingleTaskStatus helper class
**File:** `src/slack/single_task_status.py` (new)

Helper to manage single-task status lifecycle:
```python
class SingleTaskStatus:
    async def start(self, action_text: str) -> str:  # returns message_ts
    async def complete(self) -> None:  # updates to done
    async def delete(self) -> None:  # removes card
```

## Acceptance Criteria
- [ ] Single-intent requests show a status indicator while processing
- [ ] Status updates to "done" when complete
- [ ] No visual regression for multi-task TaskPlans
- [ ] Fast responses (<2s) don't leave stale cards

## Files to Modify
- `src/slack/blocks/task_plan.py` - Add single-task block builder
- `src/slack/single_task_status.py` - New helper class
- `src/slack/handlers/dispatch/__init__.py` - Integrate status posting
