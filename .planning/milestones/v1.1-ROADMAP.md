# Milestone v1.1: Communication as Source of Truth

**Status:** ✅ SHIPPED 2026-01-20
**Phases:** 11-23.5
**Total Plans:** 63

## Overview

v1.1 transforms MARO from a "Jira ticket creation bot" into a "collective thinking system" where communication is the source of truth. Key themes: conversation history, intent routing, architecture decisions, brain refactoring, and bidirectional Jira sync with conflict detection.

## Milestone Summary

**Decimal Phases (INSERTED):**
- Phase 11.1: Jira Duplicate Handling (urgent UX fix)
- Phase 11.2: Progress & Status Indicators (user feedback)
- Phase 13.1: Ticket Reference Handling (bug fix)

**Key Decisions:**
- Two-layer context (raw + compressed) for conversation history
- LLM-only intent classification with full conversation context
- ReviewState enum with 4 lifecycle states
- WorkItem as first-class citizen with drafts before Jira sync
- Field ownership classification for bidirectional sync
- Section-level fingerprinting for conflict detection
- SessionStore deprecated in favor of WorkItemStore

**Issues Resolved:**
- Bot only seeing @mention message (Phase 11)
- No visual feedback during processing (Phase 11.2)
- Intent misclassification (Phases 13, 15)
- Large file maintainability (Phase 18)
- Review continuation confusion (Phase 15, 17)

**Issues Deferred:**
- Mobile app support
- Multi-language support
- Real-time collaborative editing

**Technical Debt Incurred:**
- SessionStore still exists (deprecated, not removed)
- Some handlers have dual patterns for backward compatibility
